# Бот-воронка Orsofey + CRM

Путь человека: ролик / шортс / пост (`t.me/ИМЯ_БОТА?start=tt_v12_3`) → бот → подписка на канал → 🎁 лид-магнит → 📲 «Протестировать» → ⬇️ скачивание Агента → ⭐ подписка. Отдельная ветка: 🤖 заявка на автоматизацию → переписка → созвон → оплата.

CRM записывает каждый шаг и показывает, **на каком этапе человек застрял** (24 ч без следующего шага), с какого ролика и платформы он пришёл и сколько денег принёс каждый ролик.

## Что внутри
- **Панель CRM** (веб + приложение на телефон): вкладки «Воронка», «Контент», «Люди», «Сделки», «Настройки».
- **Учёт каждого шага**: старт с меткой, проверка подписки, лид-магнит, «Протестировать», переход к скачиванию (через ссылку бота), открытие подписки, оплата, блокировка бота.
- **Метки по платформам**: TikTok, Instagram, VK, YouTube, Telegram. Неизвестная метка сама появляется во вкладке «Контент».
- **Кодовые слова** для шортсов без кликабельной ссылки: «напиши боту АГЕНТ12» → CRM понимает, с какого ролика человек, и сразу выдаёт подарок.
- **Автоподгрузка соцсетей**: один раз подключаешь YouTube, VK, TikTok и Instagram в «Настройках» — все ролики, шортсы, Reels и посты со статистикой сами появляются во «Контенте» и обновляются каждые 3 часа. Метка ролика берётся из ссылки на бота в описании или из кодового слова в подписи — просмотры и люди из бота сходятся в одной карточке.
- **Напоминания** застрявшим: через 24 ч на каждом этапе, не чаще раза в сутки, включаются/выключаются в панели. Видно, сколько вернулось после напоминания.
- **Личная работа**: заявки на автоматизацию, переписка прямо из панели или ответом (reply) на уведомление бота в Telegram, заметки, статусы, ручная запись оплат в ₽.
- **Сводка каждый день** в 9:00 по Москве: новые люди по платформам, кто где застрял за сутки, лучший контент, оплаты, кто ждёт ответа.

## Запуск на Amvera (обновление существующего проекта)
1. Загрузи файлы проекта (или `git push`). В `amvera.yml` уже есть `containerPort: 8080`.
2. Amvera → проект бота → **Домены** → добавь бесплатный домен. Скопируй адрес.
3. **Переменные** → добавь `PUBLIC_URL` = этот адрес (например `https://orsofeybot-orsofey.mia0.amvera.tech`, без слэша в конце).
   Если раньше в переменных был `DB_PATH=data/bot.db` — удали: база должна жить в постоянном `/data/bot.db`.
4. Перезапусти проект. В логах появится «Панель CRM: порт 8080».
5. **Приватный канал**: открой канал → Администраторы → добавь бота (права не нужны). Бот сам запомнит id канала и пришлёт тебе подтверждение. Кнопка «Подписаться» ведёт на `CHANNEL_URL` (инвайт-ссылка уже прописана).
6. Напиши боту **/panel** → кнопка «Открыть CRM». На телефоне: Safari → «Поделиться» → «На экран Домой» (Android: Chrome → «Установить приложение»). В приложении с экрана «Домой» вход — 6-значным кодом из /panel.

## Публикация (кросспостинг)
CRM → «Публикация» → «Новая публикация». Тип поста: **видео**, **фото** (до 10 — альбом/карусель), **GIF** или **текст**. Пишешь заголовок и текст, кодовое слово («Придумать»), отмечаешь соцсети, «Сейчас» или «Запланировать». Внизу — **превью**: как пост будет выглядеть в каждой соцсети (Telegram, Instagram, TikTok, YouTube, VK, X, Patreon) — с твоими файлами, подписями, ссылками, счётчиком символов (X — 280, Instagram — 2200, подпись к медиа в Telegram — 1024). Подпись под отдельную соцсеть можно поправить.
- **Сама публикует CRM, сразу в соцсеть**: Telegram-канал — видео, фото/альбом, GIF, текст (бот — админ канала с правом «Публикация сообщений»; видео/GIF до 50 МБ, фото до 10 МБ); Instagram — Reels, фото и карусели; Bluesky, Pinterest, Discord, e621.
- **Тоже сама — после «Разрешить публикацию»** (Настройки → Соцсети, один раз):
  - **YouTube** — видео и шортсы (вход через Google, OAuth-клиент в Google Cloud). Пока API-проект не прошёл аудит YouTube, Google делает загруженные ролики приватными — CRM это видит и подсказывает; аудит бесплатный.
  - **TikTok** — видео и фото-посты (Content Posting API в приложении TikTok + галочка в CRM + повторный вход). До аудита TikTok ролики приходят в «Входящие» приложения TikTok — остаётся нажать «Опубликовать».
  - **VK** — посты с текстом, фото, GIF на стену сообщества (вход через VK ID; доступы к стене и фото VK открывает после верификации бизнеса — ИП подходит). Видео — когда VK выдаст приложению право «video» (по заявке); до тех пор видео уходит в «вручную».
  - **X** — текст, до 4 фото, GIF, видео (OAuth 2.0 в console.x.com; публикация через API у X платная).
  - **Fur Affinity** — картинки и GIF по cookie аккаунта (у сайта нет API; так же работают PostyBirb и аналоги), с рейтингом по метке 18+.
- **Вручную** остаются только Patreon, SubscribeStar (у них нет API для постов) и посты «Сообщества» YouTube. Всё готовое — в карточке поста: «Скачать», «Копировать», «Открыть …», «Я выложил». Присылать это ещё и в Telegram — по желанию (Настройки → Соцсети → «Присылать в Telegram файлы для ручной публикации», по умолчанию выключено). Если у ручного поста появилась возможность публиковать самой — кнопка «Опубликовать автоматически».
- Где тип не поддерживается (например, GIF в TikTok/Instagram/YouTube, текст в TikTok/Instagram), соцсеть в форме неактивна с подписью «не поддерживает».
- Подписи под каждую соцсеть: в YouTube/VK/X/Patreon — ссылка на бота с меткой, в TikTok/Instagram — «напиши боту СЛОВО», в Telegram — кнопка «Забрать подарок». Метки: `yts_p12`, `tt_p12`, `ig_p12`, `vkc_p12`, `tg_p12`, `x_p12`, `pt_p12`.
- Файлы хранятся на диске Amvera до публикации и удаляются через 3 дня после неё (максимум — через 3 недели). Лимит размера — `MAX_UPLOAD_MB`.

## Подарки по отдельной ссылке
«Воронка» → «Подарки по ссылке». Набор — своя ссылка `t.me/бот?start=skills` и свои файлы (например, скиллы из ролика).
По ссылке бот пишет своё приветствие → проверяет подписку на канал (можно выключить) → присылает файлы
(до 10 штук одним сообщением или одним .zip) → предлагает попробовать приложение. Основная ссылка с приложением не меняется.
Можно задать кодовое слово («напиши боту СКИЛЛЫ»). Люди с ссылки считаются как выбранная платформа (YouTube · Видео),
поэтому в «Аналитике» видно, сколько человек пришло с ролика; если в описании ролика стоит эта ссылка, CRM сама
привяжет к ней просмотры. Тем, кто открыл ссылку, но не забрал набор, через 24 ч приходит напоминание про набор.
Файлы лежат в /data/packs, до 50 МБ каждый. Кнопка «Прислать мне» — проверить, как набор выглядит в Telegram.
Тексты «подпишись», «а ещё у меня есть Агент» и напоминание — в bot/texts.py (PACK_*).

## Новые соцсети: Bluesky, Pinterest, Discord, Fur Affinity, e621, SubscribeStar
| Соцсеть | Подключение | Статистика | Публикация |
|---|---|---|---|
| Bluesky | кнопка «Войти через Bluesky» (OAuth, ключи не нужны; нужен PUBLIC_URL с https) или пароль приложения | подписчики, лайки+репосты, ответы | сама: текст до 300 знаков, до 4 фото, видео/GIF; 18+ — метка контента |
| Pinterest | кнопка (OAuth), ключи приложения — один раз у автора | подписчики, показы и сохранения пинов | сама: фото, карусель до 5, видео; ссылка на бота в пине. Пока приложение в пробном доступе — пины видишь только ты (галочка «Standard» после одобрения) |
| Discord | кнопка (Discord сам спросит сервер и канал) или ссылка вебхука | участники сервера (по ссылке-приглашению в ⚙), реакции на наши посты | сама: текст и файлы до 10 МБ (больше — ссылкой); 18+ только в каналы с отметкой 18+, под спойлером |
| Fur Affinity | ссылка на профиль (API у сайта нет) | наблюдатели, просмотры, избранное, комментарии — через FAExport | вручную: CRM присылает файл, описание, теги и подсказку по рейтингу |
| e621 | имя + API-ключ (OAuth у сайта нет) | избранное и комментарии работ | сама: каждая работа — пост с тегами и рейтингом s/q/e; без ссылки на бота (реклама запрещена) |
| SubscribeStar | кнопка (OAuth), .com или .adult | подписчики (поля API CRM находит сама) | вручную (API публикации нет) |

Ключи приложений Pinterest, Discord, SubscribeStar вставляются один раз в CRM автора — у клиентов кнопка «Войти» работает сразу. У каждого аккаунта ⚙: название, «публиковать сюда», доска Pinterest, канал 18+ и приглашение Discord, тег художника e621, cookie Fur Affinity.

**Метка 18+** в «Публикации»: «Без 18+» / «18+ без явных сцен» / «18+ откровенно». С 18+ CRM не даёт отправить пост в YouTube, TikTok, Instagram, VK и Pinterest (там за это банят); Telegram — только в отдельный канал 18+ (Настройки → «Публикация в Telegram»), медиа под спойлером; Discord — только в каналы с отметкой 18+, файлы под спойлером; Bluesky — метка контента; e621 — рейтинг q/e; для Fur Affinity, X, Patreon, SubscribeStar CRM напоминает, какую метку поставить.

**Расписание** — «Запланировать» в форме публикации: в нужное время CRM сама публикует во все соцсети с автопубликацией и присылает материалы для ручных.

## Выгрузка в Excel и CSV
- **Воронка** → «Выгрузить воронку: ⬇ Excel / ⬇ CSV» — за выбранный период и платформу. Листы: «Сводка», «Этапы» (людей, % от входа и от прошлого шага, застряли/в процессе/ушли), «По платформам», «Люди» (каждый человек: метка, платформа, даты всех этапов, статус, звёзды и сделки), «Личная работа».
- **Аналитика** → «Выгрузить статистику каналов: ⬇ Excel / ⬇ CSV» — за выбранный период и соцсеть. Листы: «Сводка», «Соцсети», «Аккаунты», «Публикации» (каждый ролик/пост: просмотры, лайки, комментарии, сколько людей привёл, оплаты), «Просмотры по дням», «Подписчики по дням».
- CSV — те же таблицы подряд, разделитель «;», кодировка UTF-8 с BOM (Excel и Google Таблицы открывают кириллицу правильно). Скрытые аккаунты в выгрузку не попадают.

## Аналитика
В «Сравнении соцсетей» — все соцсети (YouTube, TikTok, Instagram, VK, Telegram, X, Patreon), даже неподключённые: у них пометка «не подключено» со ссылкой в настройки. «В бота» считается так же, как в «Воронке» (по соцсети, откуда пришёл человек). Выбрана одна соцсеть — цифры и выводы только про неё.
CRM → «Аналитика»:
- **Обзор**: просмотры за период (прирост по дням, а не накопленные), подписчики и их прирост, «обычный ролик» (медиана), вовлечённость, сколько пришло в бота и сколько просмотров нужно на одного человека; график по дням (общий и по каждой соцсети), сравнение соцсетей, «Сейчас набирают», «Лучшие новые», «Больше всех привели в бота» и блок «Что говорят цифры» — выводы простыми словами (где охват, где конверсия, хиты, лучший день недели, шортсы vs длинные, ролики без связи с ботом).
- **Ролики**: каждый ролик с просмотрами, лайками, комментариями, вовлечённостью, мини-графиком роста и сравнением с обычным роликом; по нажатию — график роста, просмотры за первые сутки и путь людей с ролика по воронке.
- История копится с момента подключения соцсетей (снимок каждые 3 часа; старше 14 дней — один в день).

## Подключение соцсетей (один раз)
CRM → «Настройки» → «Соцсети — автоподгрузка». Подробные шаги — под каждой соцсетью в панели («Как получить ключ»).
- **YouTube**: ссылка на канал + API-ключ Google (YouTube Data API v3). До 500 последних роликов, шортсы отличаются сами.
- **VK**: ссылка на сообщество + сервисный ключ **мини-приложения** VK (dev.vk.com → «Создать» → «Мини-приложение»; ключ обычного приложения VK ID не работает — ошибка «method is unavailable with current profile type»). Последние 300 записей стены: посты, видео, клипы.
- **Несколько аккаунтов**: на каждую соцсеть можно добавить сколько угодно аккаунтов (два TikTok, два YouTube-канала…). YouTube, VK, X — вставь ещё одну ссылку; TikTok, Instagram, Patreon — «+ Добавить аккаунт» и войди другим аккаунтом (тот же второй раз не добавится — обновится вход). Ключи приложений общие на все аккаунты. Автопубликация в Instagram идёт в первый видимый аккаунт Instagram.
- **Скрыть / удалить**: переключатель у аккаунта прячет его из воронки, аналитики и меток — ролики, подписчиков и людей, пришедших с его роликов (вкладка «Люди» показывает всех). Данные не удаляются и продолжают обновляться. «Скрыть все» / «Показать все» — сразу для всех. ✕ удаляет аккаунт и его статистику; ролики, с которых пришли люди, остаются метками.
- **TikTok**: приложение на developers.tiktok.com (Login Kit + Display API, режим Sandbox, свой аккаунт в Target users) → Client key и secret → «Войти через TikTok». Токен продлевается сам.
- **Instagram**: профессиональный аккаунт + приложение на developers.facebook.com (Instagram API с входом через Instagram, свой аккаунт — Instagram tester) → App ID и secret → «Войти через Instagram». Токен (60 дней) продлевается сам. Просмотры обновляются для 60 последних публикаций.
- **Закрытый Telegram-канал**: добавь бота админом канала — канал появится в «Каналы, где бот админ» (Настройки → Telegram), нажми «Добавить». Или вставь ссылку-приглашение (t.me/+…) — CRM найдёт канал среди тех, где бот админ. У закрытых каналов видно подписчиков; просмотры постов Telegram отдаёт только у публичных. Новый канал больше не заменяет канал проверки подписки (его бот ставит сам только один раз — если он ещё не задан).
- **Telegram-канал**: вставь @username или ссылку на канал — ключи не нужны, работает через бота. Подписчики — точно (Bot API; для закрытого канала бот должен быть админом, можно вставить ссылку-приглашение канала проверки подписки — CRM возьмёт его id). Просмотры постов Telegram отдаёт только у публичных каналов: CRM читает до 200 последних постов со страницы t.me/s/канал. Первый добавленный канал сам становится каналом для автопубликации.
- **X (Twitter)**: имя аккаунта + Bearer Token из console.x.com. Чтение у X платное (кредиты, нужна зарубежная карта); повторное чтение поста в те же сутки не тарифицируется, поэтому при 40 постах — порядка нескольких долларов в месяц. Сколько постов читать — настраивается. X заблокирован в России — нужен прокси.
- **Patreon**: клиент на patreon.com/portal (API v2) → Client ID, Client Secret, Creator's Access Token, Creator's Refresh Token. Считает платных подписчиков, доход в месяц, новых, ушедших, отказы оплаты, уровни; токен продлевается сам. Просмотров постов Patreon не отдаёт.
- **Redirect URI** для TikTok и Instagram показан в панели — его нужно вставить в настройки приложения. Нужен заданный `PUBLIC_URL`.
- **Прокси**: сервер Amvera в России, Instagram оттуда недоступен (YouTube может тормозить). В панели можно задать HTTP-прокси за рубежом (`http://логин:пароль@адрес:порт`) или переменную `SOCIAL_PROXY` — все запросы к соцсетям пойдут через него.
- Связь ролика с людьми из бота: ссылка `t.me/ИМЯ_БОТА?start=МЕТКА` в описании или кодовое слово этой платформы в подписи (задаётся во «Контенте»). Без этого ролик всё равно загрузится (просмотры идут в охват), CRM подсветит, что люди с него не отследятся.
- **Страницы для TikTok/Instagram**: условия — `PUBLIC_URL/terms`, политика конфиденциальности — `PUBLIC_URL/privacy` (открываются без входа; контакт задаётся переменной `LEGAL_CONTACT`). Если TikTok попросит подтвердить домен (URL prefix), положи скачанный файл `tiktok….txt` в `bot/static/` — он откроется по адресу `PUBLIC_URL/tiktok….txt`.

## CRM для друзей (в этом же боте)
Друг пишет боту `/panel` → тебе приходит запрос с кнопками:
- **«Своя CRM»** — отдельное пространство (своя база в `/data/workspaces/`): свои соцсети, аналитика, публикация. Твоих людей, оплат и цифр он не видит. 
- **«Доступ к моей»** — видит твою CRM (без уведомлений и сводок).
- **«Отказать»**.
Все ключи, подключённые у тебя, работают у всех клиентов: YouTube, VK, X (чтение X — с твоего баланса кредитов), прокси, приложения TikTok, Instagram и Patreon. Клиенту нужно только вставить ссылки на свои каналы. Это можешь сделать и ты: «Настройки» → «Доступ к CRM» → «Настроить» (вход в CRM клиента, сверху плашка «← В мою CRM»). TikTok, Instagram и Patreon требуют входа самого владельца аккаунта: кнопка «Отправить ссылку для входа в Telegram» — бот присылает клиенту кнопку, он нажимает «Разрешить». Для Patreon добавь в свой клиент Patreon Redirect URI `…/oauth/patreon` (показан в панели).
После нажатия бот сам присылает другу ссылку для входа; потом он входит командой `/panel`. Изменить доступ — CRM → Настройки → «Доступ к CRM». `AUTO_WORKSPACES=1` — выдавать свою CRM всем без подтверждения.
В своей CRM друга нет воронки бота и людей (бот — твой); подписи в «Публикации» — без ссылок на бота; ручные публикации CRM находит по названию ролика. TikTok/Instagram через твоё приложение: пока оно в тестовом режиме, добавь аккаунт друга в Target users (TikTok) / тестеры (Instagram).

## Команды автора в боте
- `/panel` — код и ссылка для входа в CRM. Работает для `ADMIN_IDS` и `PANEL_IDS` (второе — доступ к панели без уведомлений и сводок). Остальным бот отвечает, что панель только для автора, и показывает их Telegram ID
- `/stats` — коротко по воронке и платформам
- `/report` — сводка за вчера прямо сейчас
- `/broadcast` — ответь этой командой на своё сообщение, и оно уйдёт всем
- **Ответ (reply) на уведомление** «💬 …» или «🤖 Заявка…» — бот перешлёт твой ответ человеку и запишет переписку в CRM.

Для людей: `/menu`, `/sub`, `/auto` (автоматизация под бизнес), кнопки в боте.

## Метки для контента
Короткая ссылка на бота через свой домен: `PUBLIC_URL/t/метка` → `t.me/бот?start=метка` (для профиля TikTok и других мест, где t.me не принимают).

| Где | Метка | Пример ссылки |
|---|---|---|
| Видео YouTube №12 | `yt_v12` | `t.me/ИМЯ_БОТА?start=yt_v12` |
| 3-й шортс из него: YouTube / TikTok / Instagram / клипы VK | `yts_v12_3`, `tt_v12_3`, `ig_v12_3`, `vkc_v12_3` | |
| Пост VK / Telegram | `vkp_45`, `tg_45` | |
| Ссылка в профиле соцсети | `tt_bio`, `ig_bio`, `yt_bio`, `vk_bio` | |

Если человек пришёл по ссылке из профиля (`tt_bio`), а потом написал кодовое слово ролика, CRM уточнит источник до конкретного ролика (первая метка тоже сохраняется). Старые метки `yt01`, `s03`, `tg01`, `tt01` тоже понимаются.

## Переменные (новые)
`PUBLIC_URL`, `CHANNEL_URL`, `PORT=8080`, `DROP_HOURS=24`, `REPORT_HOUR=9`, `TZ_NAME=Europe/Moscow`, необязательные `PANEL_PASSWORD` и `YT_API_KEY` (ключ YouTube удобнее вставить прямо в «Настройках» CRM). Остальное — как раньше (см. `.env.example`).

## Файлы
- `bot/texts.py` — все тексты бота, включая напоминания (`REMIND_START`, `REMIND_DOWNLOAD`) и автоматизацию (`AUTO_INFO`, `AUTO_THANKS`)
- `bot/db.py` — база и этапы воронки, `bot/crm.py` — аналитика и сводка, `bot/api.py` + `bot/web.py` — панель, `bot/static/` — интерфейс
- `bot/scheduler.py` — напоминания и сводка, `bot/social.py` — автоподгрузка соцсетей, `bot/publish.py` — кросспостинг, `bot/analytics.py` — аналитика

## Что проверено
Логика базы, воронки, напоминаний, сводки и API — автотестом на сгенерированной базе из 420 человек (сумма «застряли + в процессе + ушли + оплатили» = все вошедшие). Обработчики бота — прогоном всего пути на заглушках Telegram. Панель — в браузере на телефоне и компьютере, светлая и тёмная тема. Живой запуск с Telegram в песочнице невозможен — первый раз пройди путь сам: /start с меткой → подарок → тест → скачать → подписка, затем открой /panel.
